# 动态四叉树 2D 碰撞检测加速结构

用动态四叉树（Dynamic Quadtree）对一组**运动中的面积碰撞体（AABB）**做空间分区，
把碰撞检测从暴力两两比较 O(n²) 降低到接近 O(n log n)，并用暴力 O(n²) 结果作为
黄金标准逐帧验证**碰撞对集合完全一致（不多报、不漏报）**。

- Go 实现，**仅使用标准库**；
- 回放页面为**单一静态 HTML 文件**（数据与逻辑全部内嵌，无服务、无第三方 JS）；
- 自动化测试覆盖跨边界归属、高密度退化、随机差分测试与分裂/合并阈值时机。

## 运行

```bash
go test ./... -v          # 全部测试（含差分测试）
go run . -out report.html # 运行 160 对象 × 150 帧模拟并生成回放报告
open report.html          # 浏览器直接打开，逐帧回放
```

可选参数：`-seed`（场景随机种子，默认 42）、`-out`（报告路径，默认 report.html）。

运行结束后程序会打印逐帧校验结果、累计比较次数与减少比例、深度退化叶子数。

## 核心设计

### 1. 跨边界对象的归属规则

对象是**有面积的 AABB**，不是点。一个对象可能同时横跨节点的竖直/水平分割线，
简单"只进一个象限"会导致它与另一侧对象的碰撞**漏检**，而"复制进所有相交象限"
会让一个大对象在树中出现 4^depth 次、并产生重复比较。

本实现采用明确的**唯一归属策略：对象存入"能完整包含它的最小节点"**：

- 下行时，对象若**完整落入唯一子象限**则继续下行；
- 若它跨越本节点的任意一条分割线，则**保留在当前（内部）节点**中——
  内部节点本身维护一个 `items` 列表；
- 分裂时，跨界对象同样**上提保留在父节点**，能完整进入某象限的对象才下放；
- 因此每个对象在树中**恰好出现一次**（`owner` 映射保证），不存在重复比较。

**贴线的确定性规则**：恰好落在分割线上的对象按确定方向归入一侧
（`MaxX == midX` 归左，`MinX == midX` 归右；Y 同理），
保证任何对象至多落入一个子象限。AABB 相交采用闭区间语义（**边/点相切也算相交**），
四叉树与暴力法共用同一份 `Intersects` 实现，语义严格一致。

**根边界之外的对象**（未被根 Bounds 完整包含）常驻根节点；检测时根节点必被访问，
因此不丢任何比较，同时维持"对象必被其归属节点完整包含"这一不变量。

**为什么不会漏检**：对每个对象 i 用其 AABB 做范围查询，只访问包围盒与 i 相交的节点。
若对象 A、B 相交，则完整包含 B 的那个节点，其祖先路径上每个节点的包围盒都包含 B、
因而都与 A 相交，查询必然沿该路径走到 B。配合 `i < j` 的代际 stamp 去重，
每对碰撞体恰好测试一次。

### 2. 节点分裂与合并

| 机制 | 规则 |
|---|---|
| 分裂 | 叶子内对象数 `> SplitThreshold` 时，分裂为 4 个子节点；对象按归属规则下放或留父；分裂后对仍超阈值的子节点递归分裂 |
| 合并 | 任一删除/移动后，自底向上检查：某内部节点**整棵子树的唯一对象数 ≤ MergeThreshold** 时，整棵子树 `collapse` 收回为一个叶子 |
| 迟滞 | `MergeThreshold < SplitThreshold`（默认 6 < 8），对象数在两个阈值之间抖动时不反复分裂/合并 |
| 深度上限 | 分裂深度达到 `MaxDepth` 后**不再分裂**，该叶子**退化为节点内暴力两两比较** |
| 浮点兜底 | 节点宽度/高度耗尽（≤ 1e-9）时也停止分裂，防止完全重合对象导致的无限细分 |

动态对象每帧走 `Update = Remove + Insert`：移动造成的聚集实时触发分裂、
分散实时触发合并，树结构随运动持续自适应。

### 3. 最大深度的选择依据

最深层叶子的世界尺寸 ≈ `世界边长 / 2^MaxDepth`。默认世界为 1000×1000、
`MaxDepth = 7`，最深层单元约 **7.8×7.8**：

- 正常尺寸（≥ 数单位）的对象在 7 层以内就能被有效切分；
- 再深一层单元收益急剧变小，而树节点数按 4 的幂增长，内存与遍历成本上升；
- 当大量对象集中在小于最深层单元的区域（演示场景中心簇会被压缩到约 3% 散布半径），
  继续分裂没有任何区分度——此时**有意退化为该节点内的暴力比较**。
  受影响的只是那个高密度小区域内的少量对象，全局其余部分仍享受四叉树加速，
  从而在"高密度聚集"与"整体稀疏"之间取得正确且不崩溃的折中。

深度上限使树的空间复杂度有严格上界，**不会因高密度聚集而无限递归导致栈溢出或性能退化**。
测试 `TestHighDensityDegradation` 用 400 个对象塞进 2×2 区域验证：树精确停在
MaxDepth、存在超阈值的退化叶子、且结果仍与暴力法完全一致。

### 4. 正确性黄金标准

`BruteForce`（brute.go）对所有活跃对象做 n(n-1)/2 次两两比较。
四叉树检测在每一帧、以及每个随机差分测试用例上都与其做**集合差分**：

- 暴力法有、四叉树没有 → 漏报（missing）；
- 四叉树有、暴力法没有 → 多报（extra）；
- 两者必须都为空。

模拟程序在演示场景（默认种子）上的实测结果：160 对象 × 150 帧**全部一致**，
累计比较 232,953 次 vs 暴力 1,908,000 次，**平均减少约 87.8%**
（单帧区间约 60%～95%；簇被极度压缩、退化叶子较多的帧减少比例最低，符合预期）。

## 回放报告

`report.html` 是完全自包含的单文件（约 1.2MB，内嵌 150 帧 JSON）：

- Canvas 逐帧绘制对象、四叉树网格、分裂/合并过程；
- **红色填充 + 中心连线**：本帧发生碰撞的对象对；
- **橙色描边**：作为跨边界对象存储在内部节点的碰撞体；
- **红色虚线框**：达到深度上限、退化为暴力比较的叶子；
- 支持播放/暂停、单帧步进、拖动进度、0.25×～4× 变速、图层开关；
- 侧栏实时显示碰撞对数、四叉树/暴力比较次数与减少比例、节点数、退化叶子数。
