# 动态四叉树 2D 碰撞检测

基于动态四叉树的 2D 碰撞检测加速结构（仅 Go 标准库），附带单文件静态 HTML 回放页（原生 HTML/CSS/JavaScript，无任何第三方库）。

## 运行

```bash
go test ./...          # 自动化测试（含与暴力法的差分测试）
go run .               # 模拟 300 帧并生成 replay.html
go run . -seed 7 -frames 600 -out replay.html
```

用浏览器打开 `replay.html` 即可逐帧回放：对象运动、四叉树分裂合并、碰撞对高亮（红色）、跨边界对象高亮（橙色描边），并实时显示比较次数相对暴力法的减少比例。

## 正确性黄金标准

每一帧、每一个测试场景中，四叉树检测出的碰撞对集合都与暴力 O(n²) 两两比较**完全一致**（不多报、不漏报）。模拟器内部逐帧断言，不一致直接 panic；测试侧由 `TestRandomDifferential`（20 组随机种子）、`TestCrossBoundaryMatchesBruteForce`、`TestHighDensityDegenerates` 覆盖。

## 跨边界归属策略

碰撞体是有面积的 AABB，可能跨越节点分割线。采用**"归入能完整包含它的最小节点"**策略：

- 插入时，若对象能完整落入某一象限则下潜，否则**留在当前节点**（不复制到多个象限）。
- 查询时，访问所有与查询矩形重叠的节点，并检查路径上每个节点本地存放的对象。

**为什么不漏检**：若对象 o 与查询矩形 r 相交，o 所在节点的包围盒必包含 o，因此必与 r 相交，查询必然访问到该节点。
**为什么不重报**：每个对象在树中只存一份；碰撞对按 ID 升序去重（仅当 `o.ID > a.ID` 时才测试），每对至多比较一次。

该策略避免了"复制到所有重叠象限"方案的重复存储与去重开销，代价是跨边界对象会停留在较高层节点、参与更多候选比较——这正是回放中将其高亮的原因。

## 分裂与合并策略

- **分裂**：叶子节点对象数 `> Capacity`（默认 8）且未达深度上限时，分裂为四个象限子节点，能完整落入子节点的对象下移，跨线对象留下。
- **合并**：子树对象总数 `<= MergeThreshold`（默认 4）时，子节点回收、对象并回父节点。
- **迟滞区间**：合并阈值取分裂阈值的一半（4 < 8），避免对象数在阈值附近抖动时每一帧都分裂/合并（thrashing）。`TestSplitMergeThresholds` 验证切换时机：等于 Capacity 不分裂、Capacity+1 分裂、降到 MergeThreshold+1 不合并、降到 MergeThreshold 合并。

## 深度上限与高密度退化

- **MaxDepth = 6**：世界 960×640，深度 6 的叶子单元为 15×10 像素，已与典型对象尺寸（4–24px）相当——继续分裂无法再把对象分开，只会浪费内存与遍历时间。这是深度上限的选择依据：**最小单元尺寸 ≈ 最小对象尺寸**。
- 达到上限的节点不再分裂，对象全部留在该节点，候选比较自然**退化为节点内暴力两两比较**。由于比较次数有界（单节点对象数 × 查询路径），高密度聚集不会导致栈溢出（递归深度恒 ≤ 6）或性能崩溃。
- `TestHighDensityDegenerates` 用 500 个对象挤在 40×40 区域验证：树恰好分裂到深度 6 后停止，结果仍与暴力法一致。

## 比较次数统计

`FindPairs` 统计实际执行的 AABB 重叠测试次数（每个对象查询候选，仅对 ID 更大的候选测试）；暴力法恒为 n(n−1)/2。默认场景（130 个对象：90 均匀 + 40 高密度集群）300 帧累计：

```
四叉树 316,671 次 vs 暴力 2,515,500 次，减少约 87%
```

回放页侧栏实时显示每帧的比较次数与减少比例。

## 代码结构

| 文件 | 职责 |
|---|---|
| `quadtree.go` | Rect/Body、四叉树插入/移除/分裂/合并、碰撞对查询（带比较计数）、跨边界对象与节点快照 |
| `brute.go` | 暴力 O(n²) 基准与碰撞对集合比较 |
| `sim.go` | 运动模拟（匀速 + 边界反弹）、逐帧录制与一致性断言 |
| `html.go` | 单文件回放页模板（原生 Canvas，无框架） |
| `main.go` | 驱动模拟、内嵌帧数据、输出静态 HTML |
| `quadtree_test.go` | 跨边界一致性、高密度退化、随机差分、分裂/合并阈值、比较次数减少 |
